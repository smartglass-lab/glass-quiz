# グラスクイズ — Glass Quiz

Meta Ray-Ban Display 用の英語トリビアクイズ WebApp。[Open Trivia Database](https://opentdb.com/)（APIキー不要の無料クイズAPI）から毎回ランダムに10問を取得し、4択で世界のトリビアに挑戦できます。

- **ライブURL**: https://glass-quiz.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / 静的サイト）

## 特徴

- **毎回ランダムな10問** — スタートするたびに Open Trivia DB から新しい問題セットを取得。ジャンルも難易度もバラバラで飽きにくい
- **4択クイズ** — D-padで選択肢を移動、タップで解答。正解は緑、誤答は赤でその場にハイライト
- **ハイスコア記録** — 最高スコアと直近のスコアを`localStorage`に保存し、次回起動時もホーム画面に表示
- **結果に応じたメッセージ** — 正答率に応じて一言コメントが変化。ハイスコア更新時は🏆バッジ表示
- **通信エラーに強い** — 問題取得に失敗した場合はホーム画面にエラーメッセージを表示し、すぐ再挑戦できる
- すべてタップ＋D-padスライドだけで往復可能

## 操作方法

| 画面 | 操作 |
|------|------|
| ホーム画面 | 「▶ スタート」にタップで10問のクイズを開始 |
| クイズ画面 | ↑↓ で選択肢を移動、タップで解答。正誤表示のあと自動で次の問題へ |
| 結果画面 | 「↻ もう一度」で新しい問題セットに再挑戦、「← もどる」でホームへ |
| PC確認用 | Escape で戻る（グラスの戻るジェスチャーは使用不可のため補助のみ） |

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%82%AF%E3%82%A4%E3%82%BA&appUrl=https%3A%2F%2Fglass-quiz.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスクイズ`、URL `https://glass-quiz.vercel.app` を入力。
